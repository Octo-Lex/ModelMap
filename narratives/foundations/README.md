# 2017–2022 foundation narrative scaffold

This directory is for editorial synthesis derived from canonical ModelMap records. Do not duplicate canonical dates, model identities, organization links, or technique edges here as a second source of truth.

The foundation chapter should stay compressed and answer only the questions needed to understand the high-resolution 2023–2026 history:

- How did Transformer pretraining evolve from task-specific fine-tuning toward in-context learning?
- How did BERT/T5 establish alternative bidirectional and text-to-text transfer branches?
- How did empirical scaling laws and Chinchilla change how model size, data, and compute were allocated?
- How did sparse MoE, RMSNorm, SwiGLU, RoPE, and FlashAttention establish efficiency primitives later reused by open LLMs?
- How did instruction tuning, RLHF, and chain-of-thought prompting create the post-training and reasoning foundations of later systems?

Editorial prose should distinguish first publication dates from later model availability and should not imply direct conceptual ancestry unless the evidence supports it.
